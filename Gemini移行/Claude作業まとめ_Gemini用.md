### 1-1. 消防設備士 乙種6類（試験対策・進行中）
- 期間: 2026-11-17 〜 2026-11-22（いちばん最近のテーマ）
- 進め方: **「生徒（Claude）が先輩（ユーザー）に質問する」対話形式**。消火器ごとに Q1〜Q5 を出題 → ユーザーが答える → 判定（✅/⚠️/❌）と解説 → **まとめカード（表）** → **要復習リスト**を更新。
- 消火器紹介の進み具合:

| 消火器 | 状態 |
|---|---|
| 二酸化炭素 | 済 |
| 粉末 | 済 |
| 強化液 | 済 |
| 化学泡 | 済 |
| 機械泡 | **出題済み・回答待ち**（第4回: 泡のでき方／方式／消火効果／適応火災／化学泡との温度範囲の比較） |
| 水 | 未 |
| ハロン | 未 |

- 要復習リスト（最新の状態）:
  - #12 二酸化炭素消火器は**蓄圧式**（加圧式ではない）。点検は**重さ**で行う — ❌
  - #13 **K粉末の色は紫** — ❌
  - #14 粉末は**蓄圧式と加圧式の両方**がある（内部点検は蓄圧式5年・加圧式3年） — ⚠️
  - #15 強化液の薬剤は**炭酸カリウムの水溶液**（アルカリ性） — ⚠️
  - 克服済み: #2 CO₂の消火効果（窒息・冷却）、#3' ABC粉末の主成分（りん酸アンモニウム）、#5 加圧用ガス（CO₂または窒素）
- 使っている覚え方: 「抑制は、ハロー（ハロン）、粉（粉末）、強い（強化液）」、「K（カリウム）は紫」
- **次にやること**: 機械泡の Q1〜Q5 に答える → 水 → ハロン → 要復習リストの総復習

## 2. AI 動画制作

### 2-1. 唐揚げ ASMR ショート動画（Google Flow、2026-10-24 完成）
- 縦長 9:16・30秒・6ショット。セリフなし、ナレーション（心の声）と効果音のみ。
- 人物は「ひとりで食べるスーツの中年男性」という型を借りた**オリジナル人物**（実在の俳優や既存キャラクターに似せないことを決めた）。
- 人物と料理の**参照画像を1枚ずつ固定**して、全ショットで使う方針。
- 全プロンプトの末尾に付ける共通文:
  `Vertical 9:16, centered subject. No dialogue, no speech, no music. ASMR-focused, crisp detailed sound.`
- 成果物: `flow-karaage-asmr-30s.md`（制作メモとショット別プロンプト）、`karaage-asmr-combined.mp4`（クリップ1〜5をつないだ動画）

## 3. プログラム・アプリ開発

### 3-1. EDF6（地球防衛軍6）のアイテム回収を自動化するツール（2026-09-12〜09-14）
- リポジトリ: `hukuokasaga/streamlit-app-deploy`（PR #2 がマージ可能な状態）
- Python + Streamlit の画面で操作する、Windows 用のツール。**オフライン（ひとりプレイ）専用**。
- 画面のタブ:
  - 🎯 **調整**: キー6項目（前進・後退・左・右・ローリング・リロード）を1つずつ試して保存。視点の回転量を実測し `vars.turn90` に保存。
  - 🖥 **画面認識セットアップ**: 戦闘中だけ出る HUD をキャプチャして `templates/` に保存。スコアが戦闘中 0.9 以上・メニュー 0.5 未満になれば OK。
  - ▶ **実行**: dry-run（キーを送らない素振り）→ 本番。時間の上限も設定できる。
- 安全装置: **F12 で緊急停止**、**F11 で一時停止／再開**。ゲームが最前面にないときは入力しない。ミッションが終わると自動で待機。
- 起動方法（PowerShell）:
  ```
  pip install -r requirements.txt -r requirements-local.txt
  streamlit run app.py
  ```
- 詳しい説明: `docs/EDF6_ARMOR.md`
