# 第二種電気工事士 取得計画(完全初心者スタート)

作成日: 2026-10-18
目標: **2027年度(令和9年度)上期で一発合格** → 2027年8月頃に免状申請

---

## 1. 試験の概要

| 項目 | 内容 |
|---|---|
| 実施機関 | 一般財団法人 電気技術者試験センター(https://www.shiken.or.jp/) |
| 受験資格 | なし(誰でも受験可) |
| 試験回数 | 年2回(上期・下期) |
| 学科試験 | 四肢択一 50問・2時間/CBT方式(テストセンター)か筆記方式を選択 |
| 学科合格基準 | 60点以上(30問正解)が目安 |
| 技能試験 | 事前公表の候補問題13問から1問出題・40分で実際に配線作業 |
| 技能合格基準 | 「欠陥」が1つもないこと |
| 合格率(参考) | 学科 約55〜62%/技能 約70%前後 |
| 学科免除 | 学科に合格して技能に落ちた場合、**次回1回に限り**学科免除 |
| 受験手数料 | 約1万円(ネット申込の方が安い。最新額は公式で要確認) |

直近の合格率: 令和8年度上期の学科は受験者78,290人中48,692人が合格(62.2%)。前年度は、学科が上期57.7%・下期55.4%、技能が上期72.0%・下期71.4%でした。

```
2026 10月 ██ フェーズ0: 準備(教材購入・全体像をつかむ)
     11月 ████ フェーズ1: 基礎固め
     12月 ████
2027  1月 ████ フェーズ2: 学科の本番対策(過去問)
      2月 ████  ★受験申込
      3月 ████ + 工具に慣れる(週1回)
```

## 4. フェーズ別の計画

### フェーズ0: 準備(10/18〜10/31)
- [ ] 教材を買う(「2027年版」が出ていればそれを選ぶ)
  - 初心者向けの学科テキスト 1冊(例: 「すい〜っと合格」「ぜんぶ絵で見て覚える」など、図解が多いもの)
  - 学科の過去問題集 1冊(10年分程度)
- [ ] YouTubeの無料解説チャンネル(例: ホーザン、電気工事士の解説動画など)を1本見て全体像をつかむ
- [ ] 試験範囲をざっと眺める(内容は理解しなくてOK)

### フェーズ1: 基礎固め(11月〜12月)
得点しやすい「暗記」分野から始め、苦手意識をつけないようにする。
- [ ] **器具・工具・材料の名前と写真**(よく出る&暗記で取れる)
- [ ] **配線図の図記号**(毎回大量に出る。配点は最大級)
- [ ] 電気理論の超基本: オームの法則、電力 P=VI、直列・並列の合成抵抗
- [ ] 法令(電気工事士法・電気用品安全法など)の基本
- 目標: テキストを1周する(分からない計算問題は飛ばしてOK)

### フェーズ2: 学科の本番対策(1月〜3月)
- [ ] 過去問を年度ごとに解く → 間違えたところだけテキストに戻る
- [ ] 配線図問題(後半20問)を重点的にやる
- [ ] **複線図**の書き方を練習(学科にも技能にも使う最重要スキル)
- [ ] 1月から公式サイトをチェック → **申込期間に入ったらすぐ申し込む**
- [ ] 候補問題13問が公表されたら目を通しておく
- [ ] 3月から工具セットを買い、週1回ケーブルの皮むき・輪作りに慣れる
- 目標: 過去問で安定して **70点以上**(本番の余裕分を見込む)

### フェーズ3: 学科の仕上げ(4月〜5月)
- [ ] 過去問を直近10年分×2周
- [ ] 計算問題は「捨てる問題」と「取る問題」を決める(計算が苦手でも合格は可能)
- [ ] CBTの場合、**早めの日程**を予約する → 落ちても時間に余裕がなく、合格すれば技能の練習期間が長く取れる
- [ ] 学科受験 → 自己採点

### フェーズ4: 技能対策(学科受験の直後〜7月)
- [ ] **練習用の材料セット**を購入(候補問題13問を2回分練習できるセットがおすすめ)
- [ ] まず基本作業: 皮むき、輪作り、リングスリーブの圧着、差込形コネクタ、器具への結線
- [ ] 候補問題No.1〜13を1問ずつ、**複線図 → 作業**の流れで練習(1周目は時間無制限)
- [ ] 2周目は **40分以内** を意識(目標は30分で完成+見直し10分)
- [ ] 「欠陥の判断基準」(公式公表)を読み込み、自分の作品をセルフチェック
- [ ] 試験前の1週間: 苦手な問題をもう一度+ケアレスミス(ネジの締め忘れ、被覆の剥ぎすぎなど)の確認

## 5. 週間スケジュール例(学科期間)

| 曜日 | 内容 | 時間 |
|---|---|---|
| 月〜金 | 通勤時間などにテキスト・暗記(図記号・器具の写真) | 30分〜1時間 |
| 土 | 過去問1回分を解く+復習 | 2〜3時間 |
| 日 | 苦手分野(計算・複線図)の練習 | 2時間 |

技能期間は、土日のどちらかで2〜3問をまとめて練習し、平日は複線図を1日1問書く。

## 7. うまくいかなかったときの予備プラン

| ケース | 対応 |
|---|---|
| 学科に不合格 | 2027年度下期(申込は6月頃、学科は9〜10月)に再挑戦 |
| 学科は合格、技能に不合格 | 次回1回は学科免除 → 2027年度下期の技能(12月)で再挑戦 |
| 申込期間を逃した | 下期の申込(例年6月頃)を待つ。それまで技能の練習を先に進める |

---

## 8. 合格のポイント(初心者向け)

1. **暗記分野(図記号・器具・法令)で点を稼ぐ**。計算問題は全部できなくても合格できる。
2. **複線図**は早めにマスターする。学科と技能の両方で使う。
3. 技能は「きれいさ」より**「欠陥ゼロ」**が大事。時間内に完成させることを最優先にする。
4. 申込期間を逃すのが一番もったいない。**1月からカレンダーに通知を入れる。**
