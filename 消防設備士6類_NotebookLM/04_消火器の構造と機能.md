# 04 消火器の構造と機能

## 1. 燃焼と消火の原理
### (1) 燃焼の三要素
- **可燃物**、**酸素供給源**（空気など）、**点火源（熱源）**
- これに「**燃焼の連鎖反応**」を加えて「燃焼の四要素」ともいう。

### (2) 消火の方法
| 消火方法 | 内容 | 主な消火器 |
|---|---|---|
| **冷却消火** | 燃焼物の温度を下げる | 水、強化液、泡 |
| **窒息消火** | 酸素の供給を断つ（酸素濃度を下げる） | 泡、二酸化炭素、粉末 |
| **抑制消火（負触媒効果）** | 燃焼の連鎖反応を抑制する | ハロゲン化物、粉末、強化液 |
| **除去消火** | 可燃物を取り除く | （ガス栓を閉める等） |

### (3) 火災の種類
| 区分 | 名称 | 内容 | 絵表示の色 |
|---|---|---|---|
| **A火災** | 普通火災 | 木材、紙、繊維など | **白** |
| **B火災** | 油火災 | ガソリン、灯油、食用油など | **黄** |
| **C火災** | 電気火災 | 電気設備・配線など（感電の危険） | **青** |

## 2. 消火器の分類
### (1) 消火薬剤による分類
- 水系：**水消火器**、**酸アルカリ消火器**、**強化液消火器**、**泡消火器（化学泡・機械泡）**
- ガス系：**二酸化炭素消火器**、**ハロゲン化物消火器**
- 粉末系：**粉末消火器**

### (2) 加圧方式による分類
- **蓄圧式**：本体容器内に、消火薬剤と**圧縮ガス（窒素ガス・圧縮空気）**を一緒に充てんしておく。
  常に内圧がかかっているので、**指示圧力計**が付いている（CO2・ハロン1301を除く）。
- **加圧式**：使用時に圧力を発生させる。
  - **ガス加圧式**：本体内（または外）の**加圧用ガス容器**（二酸化炭素または窒素）のガスで加圧。
  - **反応式**：薬剤同士の**化学反応**で発生するガスで加圧（化学泡消火器、酸アルカリ消火器）。
- **手動ポンプ式**：手動ポンプで放射（水消火器の一部、現在はほとんどない）。

### (3) 運搬方式による分類
- **手さげ式**、**据置式**、**背負式**、**車載式**（車輪付き）

### (4) 大きさによる分類
- **大型消火器**と**小型消火器**（大型以外）

## 3. 蓄圧式と加圧式の比較
| 項目 | 蓄圧式 | 加圧式（ガス加圧式） |
|---|---|---|
| 圧力源 | 本体内に充てんした**窒素ガス**等 | **加圧用ガス容器**（CO2または窒素） |
| 常時の内圧 | **あり** | **なし**（使用時に加圧） |
| 指示圧力計 | **あり**（緑色範囲0.7〜0.98MPa） | なし |
| 放射の中断 | レバーを離せば止まる | 開閉バルブ付きは止まる、開放式は止まらない |
| 主な種類 | 粉末、強化液、水、機械泡、（CO2、ハロン） | 粉末、（強化液、機械泡の大型） |
| 内部点検 | 製造年から**5年**経過 | 製造年から**3年**経過 |
| 危険性 | 容器腐食で漏れ | **腐食容器の破裂事故**に注意 |

## 4. 各消火器の詳細

### (1) 水消火器
- 消火薬剤：**清水**、または清水に**浸潤剤**や凍結防止剤を加えたもの。
- 加圧方式：**蓄圧式**（指示圧力計付き）。以前は手動ポンプ式もあった。
- 消火作用：**冷却作用**。
- 適応火災：**普通火災（棒状）**、霧状放射なら**電気火災**にも適応。油火災には不適。

### (2) 酸アルカリ消火器
- 消火薬剤：**炭酸水素ナトリウム（NaHCO₃）水溶液**（外筒）と**硫酸（H₂SO₄）**（ガラス製アンプル）。
- 反応：2NaHCO₃ ＋ H₂SO₄ → Na₂SO₄ ＋ 2H₂O ＋ 2CO₂
- 発生した**二酸化炭素の圧力**で放射（反応式）。
- 作動方式：**破びん式**（押し金具でアンプルを割る）、**転倒式**。
- 適応火災：普通火災、霧状で電気火災。
- **現在は製造されていない**。

### (3) 強化液消火器
- 消火薬剤：**炭酸カリウム（K₂CO₃）の濃厚な水溶液**。
  - **アルカリ性**（pH約12）。中性の強化液もある。
  - **凝固点は−20℃以下**（寒冷地でも使用できる）。
- 加圧方式：**蓄圧式**が主流（指示圧力計付き）。大型には加圧式もある。
- 消火作用：**冷却作用**＋**抑制作用**（再燃防止効果もある）。
- 適応火災：**棒状 → 普通火災**のみ、**霧状 → 普通・油・電気火災すべて**に適応。
- 小型の強化液消火器は霧状ノズルのものが一般的。
- 構造：本体容器、キャップ、バルブ（レバー式）、指示圧力計、サイホン管、ホース、霧状ノズル。

### (4) 機械泡消火器
- 消火薬剤：**合成界面活性剤泡**または**水成膜泡**の水溶液。
- 加圧方式：**蓄圧式**（指示圧力計付き）が主流。大型は加圧式もある。
- 発泡の仕組み：**ノズル（発泡ノズル）で空気を吸い込み**、泡を発生させる。
  ノズルの空気吸入口をふさぐと発泡しない。
- 消火作用：**窒息作用**＋**冷却作用**。
- 適応火災：**普通火災、油火災**。電気火災には不適（泡は電気を通す）。
- 泡の膨張率：**5倍以上**（規格）。

### (5) 化学泡消火器
- 構造：**外筒**と**内筒**の二重構造。
  - **外筒**：**A剤** ＝ **炭酸水素ナトリウム（NaHCO₃）**を主成分とし、**起泡安定剤**等を加えたもの（**アルカリ性**）
  - **内筒**：**B剤** ＝ **硫酸アルミニウム（Al₂(SO₄)₃）**（**酸性**）
- 作動：消火器を**ひっくり返す（転倒させる）**とA剤とB剤が混ざり、化学反応で**二酸化炭素**を含む泡が発生し、その圧力で放射（**反応式**）。
- 反応：6NaHCO₃ ＋ Al₂(SO₄)₃ ＋ 18H₂O（結晶水等） → 3Na₂SO₄ ＋ 2Al(OH)₃ ＋ 6CO₂ ＋ 18H₂O
  - 水酸化アルミニウムを含む泡がCO2を包み、粘着性のある泡となる。
- 作動方式による種類：
  - **転倒式**：ひっくり返すだけ（小型の手さげ式）
  - **破がい転倒式**：押し金具で内筒の封板を破ってから転倒（手さげ式）
  - **開がい転倒式**：ハンドルを回して内筒のふたを開けてから転倒（大型の車載式）
- 消火作用：**窒息作用**＋**冷却作用**。
- 適応火災：**普通火災、油火災**。電気火災は不適。
- 泡の膨張率：**7倍以上**（大型は**5.5倍以上**）。
- **使用温度範囲：5℃以上40℃以下**（低温では反応が鈍くなる）。
- 本体に**安全弁**、**ろ過網**、**液面表示**がある。
- 消火薬剤は**1年ごとに交換**（劣化するため）。内部点検も**設置後1年**経過で行う。
- 指示圧力計は**ない**（常時加圧されていない）。

### (6) 二酸化炭素消火器
- 消火薬剤：**液化二酸化炭素（CO₂）**。
- 加圧方式：**蓄圧式**（自身の蒸気圧で放射）。ただし**指示圧力計はない**。
- 容器：**高圧ガス保安法**の適用を受ける高圧ガス容器。
  - 容器の外面は、表面積の**2分の1以上を緑色**（高圧ガス容器の二酸化炭素の色）、
    消火器として表面積の**4分の1以上を赤色**とする。
  - 充てん比（容器の内容積[L] ÷ 充てん質量[kg]）は**1.5以上**。
- 構造：本体容器、容器弁（レバー式）、**安全弁（封板式）**、**ホーン**（ホーン握り付き）、ホース。
- 消火作用：**窒息作用**（酸素濃度を下げる）＋ 冷却作用（気化熱）。
- 適応火災：**油火災、電気火災**。普通火災は不適。
- 長所：電気絶縁性が高い、消火後の汚損が少ない（精密機械・電気室に適する）。
- 短所：狭い密閉空間では**酸欠**の危険 → 地下街・準地下街・狭い地階等には設置禁止。
- 薬剤量の確認は**質量の測定**で行う（内部点検は行わない）。
- 充てんは**高圧ガス保安法**に基づき、専門業者（充てん所）に依頼する。
- 放射時、ホーンに触れると**凍傷**のおそれがあるため、ホーン握りを持つ。

### (7) ハロゲン化物消火器
- 消火薬剤：**ハロン1301**（ブロモトリフルオロメタン）、**ハロン1211**、**ハロン2402**など。
- 消火作用：**抑制作用（負触媒効果）**が主、窒息作用も。
- 適応火災：**油火災、電気火災**。
- **オゾン層を破壊**するため、現在は**製造中止**（特定の用途のみで使用）。
- ハロン1301消火器は指示圧力計がない（CO2と同様に質量で確認）。
- ハロン1301は毒性が比較的低く、地下街等の設置禁止の対象外。
- 容器外面は表面積の1/2以上をねずみ色（高圧ガス容器の場合）。
- ハロン番号の読み方：「炭素・フッ素・塩素・臭素」の数（例：1301＝C1・F3・Cl0・Br1）。

### (8) 粉末消火器
現在最も多く使われている消火器。

#### 消火薬剤の種類
| 粉末の種類 | 主成分 | 着色 | 適応火災 |
|---|---|---|---|
| **粉末（ABC）** | **りん酸アンモニウム**（りん酸塩類） | **淡紅色（薄いピンク）** | **A・B・C** |
| **粉末（Na）** | **炭酸水素ナトリウム** | **白色** | B・C |
| **粉末（K）** | **炭酸水素カリウム** | **紫色系** | B・C |
| **粉末（KU）** | **炭酸水素カリウムと尿素の反応物** | **ねずみ色（灰色）** | B・C |

- 粉末は**防湿処理（シリコン樹脂等）**が施されている。
- 粒径は**180μm以下**（消火薬剤の規格）。
- ABC粉末は、熱で分解して生じる**メタりん酸**が木材等の表面に**被膜**を作り、普通火災にも効果を発揮する。

#### 消火作用
- **抑制作用（負触媒効果）**＋ **窒息作用**。冷却作用はほとんどない。

#### 蓄圧式粉末消火器の構造
- 本体容器、キャップ、**バルブ（レバー・押し金具）**、**指示圧力計**、**サイホン管**、ホース、ノズル、**安全栓**、使用済み表示装置。
- 圧縮ガスとして**窒素ガス**を充てん。指示圧力計の緑色範囲 **0.7〜0.98MPa**。
- レバーを放すとバルブが閉じて放射が止まる。

#### 加圧式粉末消火器の構造
- 本体容器、キャップ、レバー、**加圧用ガス容器**、**ガス導入管**、**逆流防止装置**、
  **サイホン管**、**粉上り防止用封板**、ホース、ノズル（**ノズル栓**）、安全栓、
  使用済み表示装置、**減圧孔（排圧栓）**。
- 作動の流れ：
  1. 安全栓を抜き、レバーを握る
  2. **カッター**が加圧用ガス容器の**封板**を破る
  3. ガスが**ガス導入管**を通って本体内に入り、粉末を攪拌・加圧
  4. 加圧された粉末が**粉上り防止用封板**を破り、**サイホン管**→ホース→ノズルから放射
- 部品の役割：
  - **逆流防止装置**：ガス導入管の先端に付き、粉末がガス導入管に逆流するのを防ぐ。
  - **粉上り防止用封板**：サイホン管の先端（下端）に付き、粉末がサイホン管に入り込むのを防ぐ（湿気・固化防止）。
  - **ノズル栓**：ノズルの先端をふさぎ、湿気やごみの侵入を防ぐ。
  - **減圧孔**：キャップを外す途中で、内部の残圧を排出させる穴。
- 方式：
  - **開閉バルブ式**：レバーを放すと放射が止まる。
  - **開放式**：一度レバーを握ると全量放射するまで止まらない。
- 加圧用ガス容器の充てんガス：小型は**二酸化炭素**、大型は**窒素ガス**（または二酸化炭素と窒素の混合）が多い。

## 5. 主要部品の名称と役割
| 部品 | 役割・特徴 |
|---|---|
| **本体容器** | 消火薬剤を収める容器（鋼板、ステンレス、アルミ等） |
| **キャップ** | 本体容器の口金を閉じる。**減圧孔（減圧溝）**付き |
| **バルブ** | レバー操作で開閉（蓄圧式） |
| **レバー（握り）** | 握って放射させる操作部 |
| **安全栓** | 誤作動を防止するピン。**リング部は黄色**、内径2cm以上 |
| **使用済み表示装置** | 一度使用したことが分かる装置（使用すると脱落・変形する） |
| **指示圧力計** | 蓄圧式の内圧を表示。緑色範囲＝使用圧力範囲 |
| **サイホン管** | 容器底部の薬剤をバルブまで導く管 |
| **ホース** | 薬剤をノズルへ導く |
| **ノズル** | 薬剤を放射する。霧状・棒状・発泡ノズル等 |
| **ホーン** | CO2消火器の放射口（ラッパ状）。**ホーン握り**が付く |
| **加圧用ガス容器** | 加圧式の圧力源（CO2または窒素） |
| **ガス導入管** | 加圧用ガスを本体容器の底部へ導く管 |
| **逆流防止装置** | 粉末のガス導入管への逆流を防ぐ |
| **粉上り防止用封板** | 粉末がサイホン管内に入るのを防ぐ |
| **安全弁** | 本体内の異常な圧力上昇を逃がす（化学泡、CO2など） |
| **ろ過網** | 薬剤中のごみでノズルが詰まるのを防ぐ（化学泡など） |
| **液面表示** | 化学泡等の本体容器内面にある充てん液面の表示 |
| **内筒・内筒ふた** | 化学泡のB剤を収める容器とそのふた |
| **保持装置** | 消火器を壁に掛けるための装置 |
| **パッキン（Oリング）** | キャップ部の気密を保つ |

## 6. 指示圧力計
- **蓄圧式消火器**に取り付ける（**二酸化炭素消火器とハロン1301消火器を除く**）。
- 内部の**ブルドン管**（圧力で広がる曲がった管）の変形で指針が動く。
- **使用圧力範囲を緑色**で表示。一般的な蓄圧式消火器は **0.7〜0.98MPa**。
- 文字盤の表示：「**消火器用**」の文字、使用圧力範囲（緑色）、**圧力検出部（ブルドン管）の材質**、
  消火器の種別を示す記号（例：「**水**」「**強**」（強化液）「**泡**」「**粉**」（粉末））。
- ブルドン管の材質の記号：
  | 記号 | 材質 |
  |---|---|
  | **SUS** | ステンレス鋼 |
  | **Bs** | 黄銅 |
  | **PB** | りん青銅 |
  | **BeCu** | ベリリウム銅 |
  - 水系（強化液・機械泡・水）の消火器には腐食に強い**SUS（ステンレス鋼）**を用いる。
- 指示圧力の許容誤差：使用圧力範囲の圧力値の**上下10%以内**。
- 読み方：
  - 指針が**緑色範囲内** → 正常
  - 指針が**緑色範囲より下** → 圧力不足（ガス漏れ、使用済み）→ 消火薬剤量の確認・漏れの点検・再充てん
  - 指針が**緑色範囲より上** → 圧力過多（指示圧力計の故障の可能性、温度上昇）→ 指示圧力計の作動点検

## 7. 消火器の使い方（一般的な手さげ式）
1. **安全栓を引き抜く**（上に引き抜く）
2. **ホースを外して**ノズルを火元に向ける
3. **レバーを強く握る**
- 屋外では**風上**から、手前から**掃くように**放射する。
- 化学泡消火器は**ひっくり返して**放射する。

## 8. 消火薬剤の主な性質（まとめ）
| 消火器 | 消火薬剤 | 液性・性状 | 主な消火作用 |
|---|---|---|---|
| 水 | 清水（浸潤剤等） | 中性 | 冷却 |
| 酸アルカリ | 炭酸水素ナトリウム＋硫酸 | ― | 冷却 |
| 強化液 | 炭酸カリウム水溶液 | **アルカリ性**（中性もある）、凝固点−20℃以下 | 冷却・抑制 |
| 機械泡 | 合成界面活性剤泡、水成膜泡 | ― | 窒息・冷却 |
| 化学泡 | A剤：炭酸水素ナトリウム（アルカリ性）、B剤：硫酸アルミニウム（酸性） | ― | 窒息・冷却 |
| 二酸化炭素 | 液化CO2 | 不燃性ガス、電気絶縁性 | 窒息・冷却 |
| ハロゲン化物 | ハロン1301等 | 不燃性ガス | 抑制・窒息 |
| 粉末 | りん酸アンモニウム、炭酸水素ナトリウム等 | 防湿処理、180μm以下 | 抑制・窒息 |

## 9. その他の消火器
- **住宅用消火器**：一般住宅用。**蓄圧式**で、消火薬剤の**詰め替えができない**構造。
  「住宅用消火器」と表示される。能力単位の表示はない（適応火災の表示のみ）。
- **エアゾール式簡易消火具**：スプレー缶タイプ。検定対象ではなく、自主表示の対象。
- **自動車用消火器**：振動試験に合格したもの。
  **霧状の強化液、機械泡、二酸化炭素、ハロゲン化物、粉末**の消火器に限られる
  （水消火器・化学泡消火器は自動車用として認められない）。
