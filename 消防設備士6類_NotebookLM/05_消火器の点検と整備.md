# 05 消火器の点検と整備

主な根拠：消防用設備等の点検要領（消火器具）、消防法施行規則 第31条の6

## 1. 点検の種類と期間
- 消火器具の点検は**機器点検**（**6か月に1回**）。
  - 機器点検には「**外観点検**」と「**内部及び機能の点検**」がある。
  - 消火器具には総合点検はない（機器点検のみ）。
- 点検結果は**点検票**に記録し、特定防火対象物は1年に1回、非特定は3年に1回、消防長または消防署長に報告する。

## 2. 内部及び機能の点検（分解点検）の時期
| 消火器の種類 | 内部及び機能の点検を行う時期 | 試料の選び方 |
|---|---|---|
| **化学泡消火器** | **設置後1年**を経過したもの | **全数** |
| **加圧式消火器**（粉末以外：水・強化液・機械泡など） | **製造年から3年**を経過したもの | **全数** |
| **加圧式の粉末消火器** | **製造年から3年**を経過したもの | **抜取り方式**可 |
| **蓄圧式消火器** | **製造年から5年**を経過したもの | **抜取り方式**可 |
| **二酸化炭素消火器・ハロン1301消火器** | 内部及び機能の点検は**行わない**（質量測定で薬剤量を確認） | ― |

覚え方：「**化学泡1年、加圧3年、蓄圧5年**」

> 注意：化学泡だけ「**設置後**」、他は「**製造年から**」。

### 放射能力の点検
- 内部及び機能の点検の対象となった消火器のうち、
  **全数の10%以上**（抜取り方式の場合は、**抜き取った数の50%以上**）について**放射試験**を行う。
- **車載式の消火器**は放射能力の点検を除く。

## 3. 抜取り方式（確認試料）
- 対象：**加圧式の粉末消火器**および**蓄圧式の消火器**。
- **ロットの作り方**：**器種**（消火器の種類：粉末・強化液など）、**種別**（大型・小型）、
  **加圧方式**（蓄圧式・加圧式）が同一のものを1ロットとする。
  - 製造年から**8年を超える加圧式粉末消火器**、**10年を超える蓄圧式消火器**は、別ロットとする。
- **抜取り数**：
  - 加圧式粉末：製造年から**3年超〜8年以下** → **5年**でロット全数の確認が終了するよう概ね均等に抜き取る。
    **8年超** → **2.5年**で全数の確認が終了するよう抜き取る。
  - 蓄圧式：製造年から**5年超〜10年以下** → **5年**で全数終了。
    **10年超** → **2.5年**で全数終了。
- 判定：抜き取った試料に**欠陥がない**場合 → そのロットは良。
  欠陥があった場合 → 欠陥の内容により、そのロットの全数または関係する消火器の点検・整備を行う
  （例：消火薬剤の固化・容器内面の塗膜のはく離等は、同一メーカー・同一質量等の消火器の全数を点検）。

## 4. 耐圧性能の点検（水圧試験）
- 対象：**製造年から10年を経過**したもの、または**外観点検で本体容器に著しい腐食等**が認められたもの。
- 耐圧性能の点検を行った後は、**3年ごと**に行う。
- **二酸化炭素消火器・ハロゲン化物消火器（高圧ガス保安法の適用を受けるもの）**は除く
  （高圧ガス保安法の容器再検査による）。
- 方法：消火器の消火薬剤を全部取り出し、本体容器に水を満たして**保護枠（保護カバー）**内に置き、
  **耐圧試験機（手動水圧ポンプ）**で規定の水圧を**5分間**加え、**漏れ・変形・損傷等がない**ことを確認する。
- 合格したものには点検の記録を残す。不合格は廃棄。

## 5. 外観点検（6か月ごと、全数）
### (1) 設置状況
| 点検項目 | 確認内容 |
|---|---|
| 設置場所 | 通行・避難に支障がない、容易に持ち出せる、床面から**1.5m以下**、高温・多湿・凍結のおそれがない |
| 設置間隔 | 各部分から**歩行距離20m以下**（大型は30m以下） |
| 適応性 | 防火対象物・設置場所の火災に適応しているか（例：電気室にCO2・粉末等） |
| 耐震措置 | 転倒により消火剤が漏出するおそれのあるものに転倒防止措置 |

### (2) 表示及び標識
- 銘板（ラベル）がはがれていない、型式失効の特例期間を過ぎていないか、「消火器」の標識が見やすい位置にあるか。

### (3) 消火器本体
| 部位 | 点検内容 | 不良時の処置 |
|---|---|---|
| **本体容器** | 腐食・変形・損傷・著しい錆、溶接部の損傷がない | **著しい腐食、溶接部の損傷、変形があるものは廃棄**（破裂の危険）。錆の程度が軽ければ耐圧性能点検 |
| **安全栓の封** | 封（シール）が脱落・損傷していない | 脱落 → 使用済みの可能性 → **内部・機能点検** |
| **安全栓** | 脱落・変形がない、確実に装着されている | 交換 |
| **使用済み表示装置** | 脱落・作動していない | 作動 → 使用済み → **内部・機能点検** |
| **押し金具・レバー等** | 変形・損傷がない、確実にセットされている | 交換 |
| **キャップ** | 強度上影響のある変形・損傷・腐食、緩みがない | 締め直し、交換（腐食が著しい → 廃棄） |
| **ホース** | 亀裂・損傷・老化・詰まりがない、取付けの緩みがない | 交換、締め直し |
| **ノズル・ホーン・ノズル栓** | 変形・損傷・詰まり、ノズル栓の脱落がない | 交換、清掃 |
| **指示圧力計** | 指針が**緑色範囲内**、変形・損傷がない | 範囲外は下記参照 |
| **圧力調整器**（大型等） | 変形・損傷がない | 交換 |
| **安全弁** | 変形・損傷・緩みがない、噴き出した形跡がない | 交換、締め直し |
| **保持装置** | 変形・損傷がなく、容易に取りはずせる | 交換 |
| **車輪**（車載式） | 円滑に回転する | 修理 |
| **ガス導入管**（車載式） | 変形・損傷・緩みがない | 交換 |

### (4) 指示圧力計の指度が異常な場合
- **緑色範囲の下限より低い**：消火薬剤の量を質量で確認し、**漏れの点検**（気密試験）を行う → 再充てん。
- **緑色範囲の上限より高い**：**指示圧力計の作動不良**の可能性があるので、指示圧力計の精度を点検する。
  （気温が高い場合は一時的に上がることもある）

### (5) 消火薬剤量の確認（外観点検）
- **二酸化炭素消火器・ハロン1301消火器**は、**質量（総質量）を測定**して充てん量を確認する
  （内部及び機能の点検の対象外のため）。
- 総質量が表示値と比べて許容範囲を超えて減少 → 充てん業者に依頼して再充てん。

## 6. 内部及び機能の点検の手順

### (1) 蓄圧式消火器（粉末・強化液・機械泡など）
1. **総質量を測定**し、消火薬剤量を確認する。
2. **指示圧力計の指度**を確認する。
3. **排圧**する：
   - 排圧栓のあるものは、**排圧栓を開いて**内圧を排出する。
   - 排圧栓のないものは、**容器をさかさまにして**レバーを握り、内部のガスのみを放出する
     （消火薬剤が出ないようにするため、さかさまにする）。
4. **指示圧力計の指針が「0」**になったことを確認する。
5. 本体容器を**クランプ台**に固定し、**キャップスパナ**でキャップを緩めて外す。
6. **バルブ部分（サイホン管付き）を本体容器から抜き取る**。
7. 消火薬剤を別の容器（粉末は**ポリ袋**など）に移す。
8. 点検・清掃：
   - **本体容器内面**：**反射鏡**と**照明器具**を使って、腐食・塗膜のはく離がないか確認する。
   - **粉末の場合**：本体・サイホン管・バルブ・ホース・ノズル内を**窒素ガス（または除湿した圧縮空気）**で**吹き払って**清掃する（水を使わない）。
   - **水系（強化液・機械泡）の場合**：**水洗い**する。
   - 消火薬剤：**変色・腐敗・沈殿・汚れ・固化**（粉末は固化・塊）がないか確認する。
   - パッキン（Oリング）：変形・損傷・老化がないか。
9. **指示圧力計の作動確認**：**指示圧力計精度検査器**（または圧力ゲージ付き点検器具）で、圧力を加えて指度に誤差がないか確認する。
10. 放射能力の点検対象の場合は、放射試験を行う。

### (2) 加圧式粉末消火器
1. **総質量を測定**する。
2. 本体容器を**クランプ台**に固定する。
3. **キャップスパナ**でキャップを緩める。
   - このとき**減圧孔から残圧が噴き出した**場合は、**いったん締め直し**、残圧を排出してから再び緩める
     （排圧栓があるものは排圧栓を開いて排圧する）。
4. **加圧用ガス容器**（**安全栓を装着した状態**で）と**粉上り防止用封板**等を取り外す。
5. 消火薬剤を**ポリ袋**などに移す。
6. 点検：
   - **加圧用ガス容器**：
     - **作動封板式**（容量の小さいもの）→ **質量を測定**し、表示された総質量との差が許容範囲内か確認。封板の損傷がないか。
     - **容器弁付き**（窒素ガス等）→ **内圧を測定**。
   - **ガス導入管・サイホン管**：**エアーガン**などで窒素ガスや空気を吹き込み、**通気性（詰まり）**を確認。
   - **逆流防止装置**、**粉上り防止用封板**：変形・損傷・取付け状態。
   - **本体容器内面**：反射鏡で腐食・塗膜はく離の確認。
   - **消火薬剤**：固化・異物混入がないか。
   - **カッター・押し金具**：変形・損傷がなく、円滑に作動するか。
7. 放射能力の点検対象の場合は放射試験。

### (3) 化学泡消火器
1. キャップを外し、**内筒**を取り出す。
2. **外筒・内筒の液量**が**液面表示**の位置にあるか確認する。
3. 消火薬剤を**別の容器**（ポリバケツ）に移し、腐敗・変色・沈殿等がないか確認する。
4. 本体容器・内筒を**水洗い**し、**ろ過網**、**ホース**、**ノズル**の詰まりを清掃する。
5. **安全弁**、内筒ふた、キャップのパッキン等を点検する。
6. 消火薬剤は**1年ごとに詰め替え**る（A剤とB剤は同時に交換する）。

## 7. 整備（充てん）の手順

### (1) 蓄圧式粉末消火器の充てん
1. 本体容器内を清掃・乾燥させ、異常がないことを確認する。
2. **漏斗（ろうと）**を使って、規定量の消火薬剤を本体容器に入れる。
3. 口金部分のねじ部・パッキン部に付いた粉末を除去する。
4. **バルブ部分（サイホン管）を本体容器に差し込み**、キャップを確実に締める。
5. **窒素ガス容器**に**圧力調整器**を取り付け、**高圧エアーホース**と**継手金具**（充てん用接手）を消火器のバルブに接続する。
6. 圧力調整器の**二次側圧力**を、**温度に応じた規定の充てん圧力**に調整する
   （気温が高いほど高めに設定する：温度−圧力線図による）。
7. レバーを握って（バルブを開いて）窒素ガスを充てんし、規定圧力になったらレバーを放してバルブを閉じる。
8. **指示圧力計**が緑色範囲内を示していることを確認する。
9. **気密試験**：消火器を**水槽**に浸けて（またはせっけん水を塗って）、**気泡が出ないか（漏れがないか）**確認する。
10. **安全栓**を装着し、**封印**（シール）をする。点検・整備の記録（点検票、整備ラベル）を付ける。

### (2) 加圧式粉末消火器の充てん
1. 本体容器内・サイホン管・ガス導入管などを清掃・乾燥する。
2. **粉上り防止用封板**を新しいものに交換し、サイホン管に取り付ける。
3. 漏斗を使って規定量の消火薬剤を入れる。
4. 口金のねじ部の粉末を除去する。
5. **安全栓を装着した状態**で、新しい**加圧用ガス容器**を取り付ける
   （安全栓をセットしてから加圧用ガス容器を取り付けることで、誤ってレバーが作動しても封板が破れない）。
6. バルブ（キャップ）部分を本体容器に差し込み、キャップを確実に締める。
7. 封印・記録。

> 注意：加圧式の消火器は**加圧用ガス容器を取り付ける前に安全栓をセット**すること。

### (3) 化学泡消火器の充てん
1. 外筒・内筒を水洗いする。
2. **外筒**：**外筒の液面表示の約半分**まで水を入れ、**A剤（炭酸水素ナトリウム等）を少しずつ入れながら**よくかき混ぜて溶かし、液面表示まで水を加える。
   （外筒の外で別容器で溶かしてから入れる方法もある）
3. **内筒**：**別の容器（ポリバケツ等）**で、約半分の水に**B剤（硫酸アルミニウム）**を少しずつ入れてかき混ぜて溶かし、内筒に入れ、液面表示まで水を加える。
   - **B剤は内筒の中で直接溶かさない**（溶けにくく、内筒を傷める）。
4. 内筒にふたをして外筒に挿入し、キャップを締める。
5. **充てん年月日**を記入した点検票（ラベル）を貼る。
- 注意：A剤とB剤を**逆に入れない**、薬剤を水に溶かすとき（水に薬剤を入れる、薬剤に水を入れない）。

### (4) 二酸化炭素消火器・ハロゲン化物消火器
- **高圧ガス保安法**の規制があるため、**高圧ガス製造の許可を持つ充てん所**（専門業者・メーカー）に依頼する。

### (5) 加圧用ガス容器の交換
- 加圧用ガス容器は**再充てんしない**（作動封板式は使い捨て）。**メーカー指定の同じ型の新品と交換**する。
- 内容積**100cm³以下**の加圧用ガス容器は高圧ガス保安法の適用を受けない。
  **100cm³を超える**ものは高圧ガス保安法の適用を受ける。
- 加圧用ガス容器（二酸化炭素）の質量の許容範囲（点検要領）の目安：
  | 充てんガス量 | 許容差 |
  |---|---|
  | 5g以上10g未満 | ±0.6g |
  | 10g以上20g未満 | ±1g |
  | 20g以上50g未満 | ±2g |
  | 50g以上200g未満 | ±5g |
  | 200g以上 | ±10g |
  ※ 数値はテキストで確認すること。

## 8. 点検・整備に使う器具
| 器具 | 用途 |
|---|---|
| **キャップスパナ** | キャップの開閉 |
| **クランプ台** | 本体容器を固定する（キャップを外すとき） |
| **はかり（台秤）** | 総質量・薬剤量・加圧用ガス容器の質量の測定 |
| **反射鏡** | 本体容器の**内面**の腐食・塗膜はく離の確認 |
| **照明器具（懐中電灯）** | 本体容器内部の照明 |
| **エアーガン（エアーブロー）** | サイホン管・ガス導入管・ノズル等の通気確認・清掃（窒素ガスや圧縮空気で吹く） |
| **窒素ガス容器（ボンベ）** | 蓄圧式の充圧、粉末の清掃（容器の色は**ねずみ色**） |
| **圧力調整器** | 窒素ガス容器の高圧を規定の充てん圧力に減圧・調整（一次側・二次側の圧力計付き） |
| **高圧エアーホース、継手金具（充てん接手）** | 窒素ガス容器と消火器をつなぐ |
| **漏斗（ろうと）** | 消火薬剤を本体容器に入れる |
| **ポリ袋・ポリバケツ** | 取り出した薬剤の保管、薬剤の溶解 |
| **指示圧力計精度検査器** | 指示圧力計の作動・精度の確認 |
| **耐圧試験機（水圧ポンプ）** | 耐圧性能点検（水圧試験） |
| **保護枠（保護カバー）** | 耐圧試験時の破裂に備えた安全カバー |
| **水槽** | 充てん後の気密試験（漏れ確認） |
| **プライヤー、ドライバー、ラジオペンチ** | 部品の着脱 |
| **標準圧力計** | 圧力の確認（基準となる圧力計） |

## 9. 点検・整備の注意事項
- **腐食した加圧式消火器（特に粉末）**は、レバーを握った瞬間に**破裂する事故**が起きている。
  キャップ部・溶接部・底部の腐食が著しいものは、**分解せず廃棄**する。
- **キャップを緩める前に必ず排圧**する（蓄圧式は指針0を確認、加圧式は減圧孔に注意）。
  キャップを外すときは、**顔や体をキャップの真上に置かない**。
- **安全栓を外したまま**加圧用ガス容器を取り付けない。
- 粉末消火器の清掃は**水を使わず、乾燥した窒素ガスや圧縮空気**で行う（粉末が湿ると固化）。
- 強化液はアルカリ性なので、皮膚や目に付かないよう**保護めがね・手袋**を着用する。
- 消火薬剤は製造者の指定するものを使用し、**異なる種類の薬剤を混ぜない**。
- 二酸化炭素消火器を放射させると、ホーンが低温になり**凍傷**のおそれがある。
- 廃棄する消火器は「**消火器リサイクル推進センター**」のリサイクルシステム（特定窓口・指定引取場所）を利用する。
- 一般的な業務用消火器の設計標準使用期限は約**10年**（住宅用は約5年）が目安。

## 10. 消火器の不良と原因（よく出る）
| 現象 | 主な原因 |
|---|---|
| 蓄圧式の指示圧力計が緑色範囲より低い | ガス漏れ（パッキン劣化、バルブ不良）、使用済み |
| 加圧式粉末が放射しない・途中で止まる | 加圧用ガス容器のガス不足、ガス導入管の詰まり、薬剤の固化 |
| 粉末が固化している | 湿気の侵入（ノズル栓・粉上り防止封板・逆流防止装置の不良） |
| 化学泡の発泡が悪い | 薬剤の劣化（1年以上未交換）、低温（5℃未満） |
| 機械泡が発泡しない | ノズルの空気吸入口の詰まり |
| 本体容器の破裂 | 容器の腐食（特に底部・溶接部・キャップ部） |
