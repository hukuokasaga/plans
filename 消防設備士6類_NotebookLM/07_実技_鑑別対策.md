# 07 実技試験（鑑別等）対策

実技は**記述式で5問**。写真やイラストを見て、名称・用途・数値・手順などを答える。60%以上で合格。
※NotebookLM には写真がないため、「特徴から名称を答える」形式で練習する。

## 1. 出題パターン
1. **消火器の写真** → 消火器の名称、加圧方式、適応火災、消火薬剤の主成分を答える
2. **部品の写真** → 部品名、役割を答える
3. **点検器具の写真** → 器具名、用途を答える
4. **指示圧力計の写真** → 指針の位置から判定、必要な処置を答える
5. **銘板・絵表示** → 適応火災、能力単位の読み取り
6. **点検・整備の手順** → 正しい順序、誤りの指摘
7. **計算** → 能力単位の算定、必要本数、歩行距離

## 2. 消火器の見分け方
| 外観の特徴 | 消火器 |
|---|---|
| **指示圧力計がある**、赤い容器、ホース＋ノズル | **蓄圧式**（粉末・強化液・機械泡・水） |
| 指示圧力計がない、レバー式、安全栓あり、キャップに減圧孔 | **加圧式粉末消火器** |
| **太く短いホーン（ラッパ状）**、容器の上半分以上が**緑色** | **二酸化炭素消火器** |
| ノズルの先が太く、**空気吸入口（穴）**がある | **機械泡消火器** |
| 霧状ノズル（先が細い）、指示圧力計付き | **強化液消火器**（または水消火器） |
| レバーがなく、**キャップの上に押し金具**、本体を**さかさま**にして使う | **化学泡消火器**（破がい転倒式） |
| 車輪が付いている | **車載式**（大型消火器） |
| 容器がねずみ色 | ハロゲン化物消火器 |

## 3. 部品の名称と役割（記述できるようにする）
| 部品 | 役割（解答例） |
|---|---|
| **安全栓** | レバーが誤って握られても作動しないようにする（誤放射防止）。リング部は黄色 |
| **使用済み表示装置** | 消火器を使用したことがわかるようにする（使用すると脱落する） |
| **指示圧力計** | 蓄圧式消火器の内圧を示す。緑色範囲（0.7〜0.98MPa）なら正常 |
| **キャップ** | 本体容器の口金を密閉する |
| **減圧孔（排圧孔）** | キャップを外す途中で、容器内の残圧を逃がす |
| **サイホン管** | 本体容器の底にある消火薬剤をバルブ・ホースへ導く |
| **ガス導入管** | 加圧用ガスを本体容器の底部へ導き、粉末を攪拌・加圧する |
| **逆流防止装置** | ガス導入管に粉末が逆流するのを防ぐ |
| **粉上り防止用封板** | サイホン管に粉末が入り込むのを防ぐ（湿気・固化の防止） |
| **加圧用ガス容器** | 加圧式消火器の放射圧力源（CO2または窒素） |
| **カッター（作動軸）** | 加圧用ガス容器の封板を破る |
| **ノズル栓** | ノズルからの湿気・異物の侵入を防ぐ |
| **ホーン・ホーン握り** | CO2を放射する／放射時の凍傷を防ぐために持つ部分 |
| **安全弁** | 本体容器内の異常圧力を逃がす |
| **ろ過網** | 薬剤中のごみがノズルを詰まらせるのを防ぐ |
| **内筒** | 化学泡消火器のB剤（硫酸アルミニウム）を収める |
| **液面表示** | 化学泡の外筒・内筒の薬剤の適正な液量を示す |
| **保持装置** | 消火器を壁などに固定・保持する |
| **圧力調整器** | 窒素ガスを規定の圧力に調整する（大型消火器・充てん作業） |

## 4. 点検器具の名称と用途
| 器具 | 用途（解答例） |
|---|---|
| **キャップスパナ** | 消火器のキャップを開閉する |
| **クランプ台** | キャップの開閉時に本体容器を固定する |
| **反射鏡** | 本体容器内面の腐食・塗膜はく離を点検する |
| **エアーガン** | サイホン管・ガス導入管・ホース・ノズルの通気確認・清掃（粉末の吹き払い） |
| **圧力調整器** | 窒素ガス容器の圧力を規定の充てん圧力に調整する |
| **窒素ガス容器** | 蓄圧式消火器への蓄圧ガスの充てん（ねずみ色の容器） |
| **漏斗（ろうと）** | 消火薬剤を本体容器に充てんする |
| **はかり** | 総質量・加圧用ガス容器の質量を測定する |
| **耐圧試験機** | 本体容器の耐圧性能点検（水圧試験）を行う |
| **保護枠** | 耐圧試験時に容器が破裂しても安全なようにする |
| **指示圧力計精度検査器** | 指示圧力計の指度の誤差を確認する |
| **水槽** | 充てん後の気密試験（漏れの確認） |

## 5. 指示圧力計の読み取り
| 指針の位置 | 判定 | 処置 |
|---|---|---|
| 緑色範囲内（0.7〜0.98MPa） | 正常 | ― |
| 緑色範囲より**低い**（0付近含む） | 圧力不足（漏れ・使用済み） | 消火薬剤量を確認し、漏れの点検、整備（再充てん） |
| 緑色範囲より**高い** | 圧力過多 | 指示圧力計の作動不良の点検（精度確認） |

- 文字盤の **SUS** ＝ ブルドン管の材質がステンレス鋼。水系消火器用。
- 「**粉**」＝粉末消火器用、「**強**」＝強化液、「**泡**」＝機械泡、「**水**」＝水消火器。

## 6. 銘板の読み取り
- 例：「A-3・B-7・C」
  - 普通火災（A）の能力単位 **3**、油火災（B）の能力単位 **7**、電気火災（C）に**適応**。
- 例：「A-2・B-1」→ 電気火災に適応しない（泡消火器など）。
- 絵表示の地色：普通＝白、油＝黄、電気＝青。

## 7. よく出る記述問題（解答例付き）
**Q1. 蓄圧式粉末消火器の内部点検で、キャップを外す前に行うべき作業は？**
A. 容器をさかさまにしてレバーを握り（または排圧栓を開いて）**内圧を排出**し、指示圧力計の指針が0になったことを確認する。

**Q2. 加圧式粉末消火器のキャップを緩めたとき、減圧孔からガスが噴き出した。どうするか？**
A. いったん**キャップを締め直し**、残圧がなくなる（排圧する）まで待ってから外す。

**Q3. 加圧式粉末消火器を充てんするとき、加圧用ガス容器を取り付ける前に必ず行うことは？**
A. **安全栓を装着**する（誤作動で封板が破れるのを防ぐため）。

**Q4. 化学泡消火器のB剤を溶かすときの注意点は？**
A. **内筒の中で直接溶かさず**、別の容器（ポリバケツ）で水に少しずつ入れて溶かしてから内筒に入れる。

**Q5. 粉末消火器の本体容器内部の清掃方法は？**
A. 水は使わず、**窒素ガスまたは除湿した圧縮空気**で吹き払う。

**Q6. 蓄圧式消火器の充てん後に行う、漏れの確認方法は？**
A. **水槽に浸けて気泡が出ないか確認する**（気密試験）。

**Q7. 耐圧性能の点検を行う時期は？**
A. **製造年から10年**を経過したもの（または本体容器に著しい腐食等があるもの）。その後は**3年ごと**。

**Q8. 二酸化炭素消火器の消火薬剤量の確認方法は？**
A. **総質量を測定**する（内部点検は行わない）。

**Q9. CO2消火器を設置してはいけない場所は？**
A. **地下街、準地下街**、換気について有効な開口部の面積が床面積の**1/30以下**で、床面積が**20㎡以下**の地階・無窓階・居室。

**Q10. 化学泡消火器の消火薬剤の交換時期は？**
A. **1年ごと**（設置後1年経過したら内部点検とともに詰め替え）。

## 8. 計算問題の練習
**問1**：物品販売店舗（(4)項）、延べ面積1,200㎡、耐火構造でない。必要な能力単位は？
→ 1,200 ÷ 100 ＝ **12単位以上**

**問2**：上記が主要構造部耐火構造、内装難燃材料の場合は？
→ 1,200 ÷ 200 ＝ **6単位以上**

**問3**：A-3の粉末消火器で問2を満たすには何本必要か？
→ 6 ÷ 3 ＝ **2本以上**（ただし、歩行距離20m以下の配置も満たす必要があり、本数が増える場合がある）

**問4**：事務所（(15)項）、延べ面積250㎡。消火器の設置義務はあるか？
→ (15)項は**300㎡以上**で設置義務 → 250㎡は**設置義務なし**（ただし地階・無窓階・3階以上で床面積50㎡以上の階は必要）

**問5**：ボイラー室 床面積 60㎡ に必要な付加設置の能力単位は？
→ 60 ÷ 25 ＝ 2.4 → **3単位以上**（2.4以上を満たす能力単位）

**問6**：変電室 床面積 180㎡ に必要な付加設置は？
→ 100㎡以下ごとに1個 → **2個**（電気火災に適応するもの）

**問7**：病院（(6)項イ）、延べ面積800㎡、主要構造部耐火構造・内装難燃。能力単位は？
→ 100 × 2 ＝ 200㎡ → 800 ÷ 200 ＝ **4単位以上**

**問8**：映画館（(1)項イ）、延べ面積 300㎡、耐火構造でない。能力単位は？
→ 300 ÷ 50 ＝ **6単位以上**
