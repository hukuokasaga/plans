# 02 消防関係法令（類別部分：消火器の設置基準）

主な根拠：消防法施行令 第10条、消防法施行規則 第6条〜第11条

## 1. 消火器具とは
- **消火器具** ＝ **消火器** ＋ **簡易消火用具**
- **簡易消火用具**：**水バケツ、水槽、乾燥砂、膨張ひる石または膨張真珠岩**
- 消火器は「**大型消火器**」と「**小型消火器**」（大型以外）に分けられる。

## 2. 消火器具の設置が必要な防火対象物（令第10条第1項）

### (1) 延べ面積に関係なく、すべてに設置
| 項 | 用途 |
|---|---|
| (1)イ | 劇場、映画館、演芸場、観覧場 |
| (2) | キャバレー、遊技場、性風俗店、カラオケボックス等（イ〜ニすべて） |
| (3) | 待合・料理店・飲食店のうち、**火を使用する設備または器具**を設けたもの（防火上有効な措置を講じたものを除く） |
| (6)イ(1)〜(3) | 病院、**有床**診療所、**有床**助産所 |
| (6)ロ | 老人短期入所施設、特別養護老人ホーム等 |
| (16の2) | 地下街 |
| (16の3) | 準地下街 |
| (17) | 重要文化財等 |
| (20) | 舟車 |

### (2) 延べ面積 **150㎡以上** で設置
| 項 | 用途 |
|---|---|
| (1)ロ | 公会堂、集会場 |
| (3) | 待合・料理店・飲食店（上記(1)に該当しないもの） |
| (4) | 百貨店、物品販売店舗等 |
| (5) | 旅館・ホテル、共同住宅等（イ・ロ） |
| (6)イ(4) | **無床**診療所、**無床**助産所 |
| (6)ハ・ニ | デイサービス・保育所、幼稚園等 |
| (9) | 公衆浴場（イ・ロ） |
| (12) | 工場、作業場、映画スタジオ等 |
| (13) | 車庫、駐車場、格納庫 |
| (14) | 倉庫 |

### (3) 延べ面積 **300㎡以上** で設置
| 項 | 用途 |
|---|---|
| (7) | 学校 |
| (8) | 図書館、博物館、美術館 |
| (10) | 停車場、発着場 |
| (11) | 神社、寺院、教会 |
| (15) | その他の事業場（事務所） |

覚え方：**「学・図・駅・神・事務所」は300㎡**（文化的・公共的な用途）。

### (4) その他、面積にかかわらず設置が必要なもの
- **少量危険物**（指定数量の**1/5以上、指定数量未満**）を貯蔵し、または取り扱うもの
- **指定可燃物**（危険物の規制に関する政令 別表第四で定める数量以上）を貯蔵し、または取り扱うもの

### (5) 階に対する設置（令第10条第1項第5号）
- 上記で設置義務がない防火対象物でも、
  **地階、無窓階、3階以上の階**で、その階の**床面積が50㎡以上**のものには、その**階**に設置する。

> ひっかけ注意：
> - 「劇場(1)イ」は面積不問だが、「公会堂(1)ロ」は150㎡以上。
> - 「病院・有床診療所」は面積不問、「無床診療所」は150㎡以上。
> - 「事務所(15)」は300㎡以上。「工場(12)」は150㎡以上。

## 3. 必要な能力単位の算定（規則第6条）

### (1) 基本の計算式
**必要な能力単位 ＝ 延べ面積（または床面積）÷ 算定基準面積**（以上の数値）

### (2) 算定基準面積
| 算定基準面積 | 防火対象物 |
|---|---|
| **50㎡** | (1)イ、(2)、(16の2)、(16の3)、(17) |
| **100㎡** | (1)ロ、(3)、(4)、(5)、(6)、(9)、(12)、(13)、(14) |
| **200㎡** | (7)、(8)、(10)、(11)、(15) |

→ 設置義務の面積区分（不問／150㎡／300㎡）と、算定基準面積（50／100／200）はおおむね対応している。
（ただし(3)項と(6)項イ等は面積不問でも算定基準面積は100㎡）

### (3) 耐火構造の特例（2倍）
- **主要構造部を耐火構造**とし、かつ**壁及び天井の室内に面する部分の仕上げを難燃材料**
  （不燃材料・準不燃材料を含む）としたものは、算定基準面積を**2倍**の数値とする。
  - 50㎡ → **100㎡**、100㎡ → **200㎡**、200㎡ → **400㎡**

### (4) 計算例
- **例1**：飲食店（(3)項）、延べ面積600㎡、耐火構造・内装難燃
  → 算定基準面積 100㎡×2＝200㎡ → 600÷200＝**3** → 能力単位 **3以上**
- **例2**：事務所（(15)項）、延べ面積1,000㎡、耐火構造でない
  → 算定基準面積 200㎡ → 1,000÷200＝**5** → 能力単位 **5以上**
- **例3**：劇場（(1)項イ）、延べ面積900㎡、耐火構造・内装難燃
  → 50㎡×2＝100㎡ → 900÷100＝**9** → 能力単位 **9以上**
- 割り切れない場合は**切り上げ**（例：450÷200＝2.25 → 3単位以上）

### (5) 能力単位とは
- 消火器の消火能力を表す数値。**A火災（普通火災）**と**B火災（油火災）**について、
  消火試験の結果で決まる（例：「A-3・B-7・C」）。
- **C（電気火災）には能力単位の数値はない**（適応するかどうかのみ）。
- 小型消火器は能力単位**1以上**。
- 大型消火器は能力単位 **A-10以上 または B-20以上**。

## 4. 付加設置（追加で必要な消火器）（規則第6条）

| 場所・物件 | 必要な消火器 |
|---|---|
| **少量危険物**を貯蔵・取扱う場所 | 能力単位 ≧ **危険物の数量 ÷ 指定数量** |
| **指定可燃物**を貯蔵・取扱う場所 | 能力単位 ≧ **指定可燃物の数量 ÷ （危政令別表第四の数量 × 50）** |
| **電気設備**のある場所（変圧器、配電盤その他これらに類する電気設備） | 床面積 **100㎡以下ごとに1個**（電気火災に適応する消火器） |
| **多量の火気を使用する場所**（鍛造場、ボイラー室、乾燥室、厨房など） | 能力単位 ≧ **床面積 ÷ 25㎡** |

- 指定可燃物を**危政令別表第四の数量の500倍以上**貯蔵・取扱う場合は、**大型消火器**の設置が必要。

### 計算例
- ボイラー室 床面積 100㎡ → 100÷25＝**4** → 能力単位4以上の消火器を追加
- 変電設備の部屋 床面積 250㎡ → 100㎡以下ごとに1個 → 250÷100＝2.5 → **3個**
- ガソリン（指定数量200L）を100L貯蔵 → 少量危険物（1/5＝40L以上） → 100÷200＝**0.5** → 能力単位0.5以上（実際は1単位以上の消火器）

## 5. 消火器の配置（規則第6条・第7条）
- **歩行距離**：防火対象物の階ごとに、その各部分から一の消火器具に至る歩行距離が **20m以下** となるように配置する。
- **大型消火器**：各部分から歩行距離 **30m以下** となるように配置する。
- 「歩行距離」は**実際に歩く経路の距離**で、直線距離（水平距離）ではない。

> 比較：屋内消火栓（1号）は水平距離25m、自火報の発信機は歩行距離50m など他類と混同しない。

## 6. 設置場所の基準（規則第9条）
- **床面からの高さが1.5m以下**の箇所に設ける（消火器の上端（最上部）が1.5m以下）。
- 水その他消火剤が**凍結し、変質し、または噴出するおそれが少ない**箇所に設ける。
- 地震による震動等により**転倒するおそれ**がある場合は、**転倒を防止するための適当な措置**を講じる。
  - ただし、**粉末消火器その他転倒により消火剤が漏出するおそれのない消火器**は除く。
- 通行・避難に支障がなく、使用に際して容易に持ち出せる箇所に設ける。

## 7. 標識（規則第9条）
消火器具を設置した箇所には、見やすい位置に次の標識を設ける。
| 消火器具 | 標識の表示 |
|---|---|
| 消火器 | 「**消火器**」 |
| 水バケツ | 「**消火バケツ**」 |
| 水槽 | 「**消火水槽**」 |
| 乾燥砂 | 「**消火砂**」 |
| 膨張ひる石・膨張真珠岩 | 「**消火ひる石**」 |

## 8. 簡易消火用具の能力単位（規則第2条）
| 簡易消火用具 | 条件 | 能力単位 |
|---|---|---|
| 水バケツ | 容量**8L以上**の消火専用バケツ **3個** | **1** |
| 水槽 | 容量**80L以上**の水槽＋消火専用バケツ（8L以上）**3個以上** | **1.5** |
| 水槽 | 容量**190L以上**の水槽＋消火専用バケツ（8L以上）**6個以上** | **2.5** |
| 乾燥砂 | **50L以上**の一塊＋スコップ | **0.5** |
| 膨張ひる石・膨張真珠岩 | **160L以上**の一塊＋スコップ | **1** |

- **簡易消火用具の能力単位の合計**は、消火器と合わせた全体の能力単位の **2分の1を超えて算入できない**
  （アルカリ金属の過酸化物等を貯蔵する場合を除く）。

## 9. 消火器具の減免（規則第8条）

### (1) 消火設備を設置した場合
- **屋内消火栓設備、スプリンクラー設備、水噴霧消火設備、泡消火設備、不活性ガス消火設備、
  ハロゲン化物消火設備、粉末消火設備**を技術上の基準に従って設置し、
  その対象物の消火に**適応**するものであるときは、
  その設備の**有効範囲内**の部分について、消火器具の能力単位の数値の合計数を
  **3分の1まで減少**することができる。
- ただし、**11階以上の部分**には適用しない（減少できない）。

### (2) 大型消火器を設置した場合
- 大型消火器を設置し、対象物に適応するときは、その**有効範囲内**の部分について、
  小型消火器等の能力単位の数値の合計数を **2分の1まで減少**することができる。

### (3) 大型消火器の設置義務がある場合の減免
- 大型消火器を設置すべき防火対象物に、屋内消火栓設備・スプリンクラー設備・水噴霧・泡・
  不活性ガス・ハロゲン化物・粉末消火設備を設置した場合は、
  その有効範囲内の部分について**大型消火器を設置しないことができる**。

> 覚え方：**消火設備で1/3まで**、**大型消火器で1/2まで**。11階以上は減免なし。
> ※屋外消火栓・動力消防ポンプも、条件によって減免の対象となる場合がある。

## 10. 消火器の適応性（令別表第二）

| 消火器の種類 | 普通火災(A) | 油火災(B) | 電気火災(C) |
|---|---|---|---|
| 水（棒状） | ○ | × | × |
| 水（霧状） | ○ | × | ○ |
| 強化液（棒状） | ○ | × | × |
| 強化液（霧状） | ○ | ○ | ○ |
| 泡（化学泡・機械泡） | ○ | ○ | × |
| 二酸化炭素 | × | ○ | ○ |
| ハロゲン化物 | × | ○ | ○ |
| 粉末（りん酸塩類＝ABC） | ○ | ○ | ○ |
| 粉末（炭酸水素塩類＝BC） | × | ○ | ○ |
| 酸アルカリ（棒状） | ○ | × | × |
| 酸アルカリ（霧状） | ○ | × | ○ |

ポイント：
- **油火災に水は不適**（油が飛散し火災拡大）。強化液は**霧状なら**油火災に適応。
- **電気火災に泡・棒状は不適**（感電のおそれ）。
- **CO2・ハロゲン化物・BC粉末は普通火災に不適**。
- **ABC粉末と霧状強化液はA・B・Cすべてに適応**。
- 電気設備の付加設置には、電気火災に適応するもの（霧状強化液、CO2、ハロゲン化物、粉末、霧状水）。

### 危険物等に対する適応
- 第4類危険物（引火性液体）：泡、霧状強化液、CO2、ハロゲン化物、粉末が適応。
- アルカリ金属の過酸化物、禁水性物質：**乾燥砂**、膨張ひる石・膨張真珠岩、炭酸水素塩類等の粉末。水系は不適。

## 11. 設置の禁止（規則第11条）
- **二酸化炭素消火器**、**ハロン2402**及び**ハロン1211**を消火剤とする消火器は、
  次の場所に設置してはならない。
  - **地下街**
  - **準地下街**
  - **地階、無窓階または居室**で、換気について有効な開口部の面積が床面積の**30分の1以下**で、
    かつ**床面積が20㎡以下**のもの
- **ハロン1301消火器は除く**（毒性が低いため設置可能）。
- 理由：狭い密閉空間で放射すると、**酸欠・中毒**のおそれがあるため。

## 12. 大型消火器の設置
- **指定可燃物**を危政令別表第四で定める数量の**500倍以上**貯蔵・取扱う場合に必要。
- 歩行距離**30m以下**ごとに配置。
- 大型消火器の消火剤量・能力単位は規格（06のファイル）を参照。
