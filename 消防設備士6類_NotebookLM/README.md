# 消防設備士 乙種第6類 NotebookLM 学習セット

NotebookLM に読み込ませて、**質問・クイズ・フラッシュカード・音声解説**で
消防設備士 乙種第6類（消火器）の試験対策をするためのソース一式です。

> ⚠️ この資料は AI が作成した学習用まとめです。法令は改正されることがあります。
> 重要な数値は、最新の市販テキスト・e-Gov 法令検索・消防試験研究センターの情報で必ず確認してください。

## 2. NotebookLM への取り込み手順

1. https://notebooklm.google.com を開き「新規作成（ノートブックを作成）」
2. 「ソースを追加」→「ファイルをアップロード」で `00`〜`09` の `.md` をまとめて選択
   - GitHub の場合：フォルダを開き、各ファイルの「Download raw file」で保存するか、
     リポジトリを「Code → Download ZIP」で取得してから選択
3. （任意）公式・一次情報もソースに追加すると精度が上がります
   - 一般財団法人 消防試験研究センター（受験案内）: https://www.shoubo-shiken.or.jp/
   - e-Gov 法令検索：「消防法」「消防法施行令」「消防法施行規則」
     「消火器の技術上の規格を定める省令」「消火器用消火薬剤の技術上の規格を定める省令」
4. ノートブック名を「消防設備士6類 試験対策」などにする

## 3. チャットの設定（おすすめ）

チャット右上の設定（「ノートブックを設定」/会話のスタイル → カスタム）に以下を貼り付けます。

```
あなたは消防設備士 乙種第6類の試験対策講師です。
・回答は日本語で、ソースに書かれた内容を根拠にしてください。
・数値（面積、距離、年数、圧力など）は必ず明示し、覚え方のコツがあれば添えてください。
・私が答えを間違えたら、正解・理由・関連してよく出るひっかけを説明してください。
・ソースに無い内容は「ソース外」と明記してください。
```

## 4. そのまま使える質問プロンプト例

- 「法令（共通）から4択問題を10問出して。1問ずつ出題し、私の回答後に解説して」
- 「消火器の設置基準で、延べ面積に関係なく設置が必要な防火対象物を表にして」
- 「能力単位の計算問題を、耐火構造・内装難燃の2倍規定を含めて5問作って」
- 「加圧式粉末消火器の内部点検の手順を順番に並べ替えるクイズを出して」
- 「蓄圧式と加圧式の違いを、構造・点検周期・注意点で比較して」
- 「規格で『動作数』の決まりを、ひっかけ問題3問で確認させて」
- 「実技の鑑別で出そうな部品名を、写真がない前提で特徴から当てるクイズにして」
- 「私の苦手分野は（例：基礎知識の応力計算）です。易→難で5問作って」
- 「試験前日に見る、重要数値だけのチェックリストを作って」

## 5. Studio 機能の活用

| 機能 | おすすめの使い方 |
|---|---|
| **音声解説（Audio Overview）** | 「日本語で、消火器の種類と適応火災を初心者向けに」→ 通勤中に聞く |
| **フラッシュカード** | `09_重要数値・暗記カード.md` を中心に作成 → 毎日の暗記 |
| **クイズ** | 分野を指定して生成（例：「点検と整備だけ」） |
| **学習ガイド** | 試験1週間前に全体の要点整理 |
| **マインドマップ** | 消火器の種類 → 薬剤 → 適応火災 → 点検周期 のつながりを把握 |

## 6. 学習の進め方（目安：約1か月）

1. **1週目**：00 → 04（構造・機能）→ 06（規格）を読み、音声解説で全体像をつかむ
2. **2週目**：01・02（法令）→ 09 の数値をフラッシュカードで暗記
3. **3週目**：03（基礎知識）→ 05（点検・整備）→ 07（実技）
4. **4週目**：08 の練習問題 ＋ NotebookLM のクイズを繰り返し、間違えた分野を質問で深掘り
