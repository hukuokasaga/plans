各問題は4択。正解と解説を問題の直後に示す。NotebookLM には「08の問題を1問ずつ出題して、私が答えたら解説して」と依頼するとよい。

## 第1部 消防関係法令（共通）

### 問1
特定防火対象物に該当しないものはどれか。
1. 飲食店
2. 共同住宅
3. 幼稚園
4. 旅館

**正解：2**
解説：共同住宅は(5)項**ロ**で非特定防火対象物。飲食店(3)ロ、幼稚園(6)ニ、旅館(5)イはいずれも特定防火対象物。

### 問2
消防用設備等の定期点検の結果を消防長または消防署長に報告する期間として、正しいものはどれか。
1. 特定防火対象物は6か月に1回、非特定は1年に1回
2. 特定防火対象物は1年に1回、非特定は3年に1回
3. 特定防火対象物は1年に1回、非特定は2年に1回
4. すべての防火対象物で1年に1回

**正解：2**
解説：報告は特定1年に1回、非特定3年に1回。点検自体は機器点検6か月、総合点検1年。

### 問3
消防設備士の講習について、正しいものはどれか。
1. 免状の交付を受けた日から5年以内に受講する
2. 免状の交付を受けた日以後における最初の4月1日から2年以内に受講し、その後は講習を受けた日以後における最初の4月1日から5年以内ごとに受講する
3. 消防設備士の業務に従事している者のみ受講義務がある
4. 講習は消防長が行う

**正解：2**
解説：「最初の4月1日から2年以内、以後5年以内ごと」。業務に従事していなくても免状保持者は受講義務がある。講習は都道府県知事が行う。

### 問4
消防設備士免状について、誤っているものはどれか。
1. 免状は都道府県知事が交付する
2. 免状を亡失して再交付を受けた者が、亡失した免状を発見した場合は10日以内に提出しなければならない
3. 住所を変更したときは、遅滞なく免状の書換えを申請しなければならない
4. 免状の添付写真が撮影から10年を経過したときは書換えを申請する

**正解：3**
解説：住所は免状の記載事項ではないため、住所変更による書換えは不要。氏名・本籍地の都道府県の変更や写真10年経過で書換えが必要。

### 問5
消防用設備等を設置した場合に、消防長または消防署長に届け出て検査を受けなければならない期限はどれか。
1. 工事着手の10日前まで
2. 工事完了の日から4日以内
3. 工事完了の日から7日以内
4. 工事完了の日から10日以内

**正解：2**
解説：設置届は関係者が「工事完了後4日以内」。「着工10日前」は甲種消防設備士の着工届。

### 問6
基準が改正された場合でも、既存の防火対象物に常に改正後の基準が適用されるものはどれか。
1. 屋内消火栓設備
2. スプリンクラー設備
3. 消火器
4. 連結送水管

**正解：3**
解説：消火器、避難器具、誘導灯、漏電火災警報器、非常警報器具・設備などは常に遡及適用される。

### 問7
消防の用に供する機械器具等の検定について、正しいものはどれか。
1. 型式承認は日本消防検定協会が行う
2. 型式適合検定は総務大臣が行う
3. 検定に合格した旨の表示がない消火器は、販売の目的で陳列してはならない
4. 二酸化炭素の消火器用消火薬剤は検定の対象である

**正解：3**
解説：型式承認は総務大臣、型式適合検定は日本消防検定協会または登録検定機関。消火器用消火薬剤のうち二酸化炭素は検定対象外。

### 問8
消火活動上必要な施設に該当しないものはどれか。
1. 排煙設備
2. 連結送水管
3. 非常コンセント設備
4. 動力消防ポンプ設備

**正解：4**
解説：動力消防ポンプ設備は「消火設備」。消火活動上必要な施設は排煙設備、連結散水設備、連結送水管、非常コンセント設備、無線通信補助設備。

### 問9
消防設備士または消防設備点検資格者に点検させなければならない防火対象物はどれか。
1. 延べ面積500㎡の飲食店
2. 延べ面積1,000㎡の物品販売店舗
3. 延べ面積800㎡の病院
4. 延べ面積900㎡の旅館

**正解：2**
解説：特定防火対象物で延べ面積1,000㎡以上が対象（特定一階段等防火対象物は面積不問）。

### 問10
既存防火対象物で、改正後の基準に適合させなければならない増改築の規模として、正しいものはどれか。
1. 床面積500㎡以上、または延べ面積の3分の1以上
2. 床面積1,000㎡以上、または延べ面積の2分の1以上
3. 床面積1,000㎡以上、または延べ面積の3分の1以上
4. 床面積1,500㎡以上、または延べ面積の2分の1以上

**正解：2**

## 第2部 消防関係法令（類別）

### 問11
延べ面積に関係なく、消火器具を設置しなければならない防火対象物はどれか。
1. 事務所
2. 共同住宅
3. 地下街
4. 図書館

**正解：3**
解説：地下街(16の2)は面積不問。事務所(15)・図書館(8)は300㎡以上、共同住宅(5)ロは150㎡以上。

### 問12
主要構造部を耐火構造とし、内装を難燃材料とした延べ面積1,500㎡の事務所に必要な消火器の能力単位の合計はいくつ以上か。
1. 3.75
2. 5
3. 7.5
4. 15

**正解：1**（3.75以上 → 実際には4単位以上を確保）
解説：事務所の算定基準面積は200㎡、耐火・難燃で2倍の400㎡。1,500÷400＝3.75。

### 問13
消火器の配置について、正しいものはどれか。
1. 小型消火器は各部分から水平距離20m以下
2. 小型消火器は各部分から歩行距離20m以下
3. 大型消火器は各部分から歩行距離20m以下
4. 大型消火器は各部分から水平距離30m以下

**正解：2**
解説：小型は歩行距離20m以下、大型は歩行距離30m以下。

### 問14
二酸化炭素消火器を設置してはならない場所はどれか。
1. 電気室（地上階、床面積100㎡）
2. 地下街
3. 駐車場（地上階）
4. 事務所の居室（床面積50㎡）

**正解：2**
解説：地下街・準地下街、開口部が床面積の1/30以下で床面積20㎡以下の地階・無窓階・居室には、CO2・ハロン2402・ハロン1211消火器は設置不可。

### 問15
変圧器・配電盤などの電気設備がある場所に付加設置する消火器の基準として正しいものはどれか。
1. 床面積25㎡以下ごとに1個
2. 床面積50㎡以下ごとに1個
3. 床面積100㎡以下ごとに1個
4. 床面積150㎡以下ごとに1個

**正解：3**
解説：電気設備は100㎡以下ごとに1個。多量の火気を使用する場所は「床面積÷25㎡」の能力単位。

### 問16
簡易消火用具の能力単位について、誤っているものはどれか。
1. 容量8L以上の水バケツ3個で能力単位1
2. 容量80L以上の水槽と消火専用バケツ3個以上で能力単位1.5
3. 乾燥砂50L以上の一塊とスコップで能力単位1
4. 膨張ひる石160L以上の一塊とスコップで能力単位1

**正解：3**
解説：乾燥砂50L以上＋スコップは能力単位**0.5**。

### 問17
屋内消火栓設備を設置した場合、その有効範囲内の部分について消火器具の能力単位の合計数を最大どこまで減少できるか。
1. 2分の1
2. 3分の1
3. 4分の1
4. 減少できない

**正解：2**
解説：消火設備の設置で1/3まで減少可（11階以上の部分は不可）。大型消火器の設置では1/2まで。

### 問18
消火器の設置について、誤っているものはどれか。
1. 床面からの高さ1.5m以下の箇所に設ける
2. 消火器を設置した箇所には「消火器」と表示した標識を設ける
3. 粉末消火器も、地震による転倒防止措置を必ず講じなければならない
4. 消火剤が凍結・変質するおそれが少ない箇所に設ける

**正解：3**
解説：粉末消火器その他転倒により消火剤が漏出するおそれのないものは、転倒防止措置の対象外。

## 第3部 機械に関する基礎的知識

### 問19
直径20mmの丸棒に6,280Nの引張荷重が作用したときの引張応力として、最も近いものはどれか。（π＝3.14）
1. 5N/mm²
2. 10N/mm²
3. 20N/mm²
4. 40N/mm²

**正解：3**
解説：断面積＝3.14×10²＝314mm²。応力＝6,280÷314＝20N/mm²。

### 問20
軟鋼の応力−ひずみ線図において、荷重を増したときに現れる順序として正しいものはどれか。
1. 弾性限度 → 比例限度 → 降伏点 → 極限強さ
2. 比例限度 → 弾性限度 → 降伏点 → 極限強さ
3. 比例限度 → 降伏点 → 弾性限度 → 極限強さ
4. 降伏点 → 比例限度 → 弾性限度 → 極限強さ

**正解：2**

### 問21
熱処理について、誤っているものはどれか。
1. 焼入れは、高温から急冷して硬さを増す
2. 焼戻しは、焼入れした鋼に粘り強さを与える
3. 焼なましは、加熱後に急冷して材料を硬くする
4. 焼ならしは、加熱後に空気中で冷却し組織を均一にする

**正解：3**
解説：焼なましは加熱後に**徐冷**して軟らかくする。

### 問22
黄銅（真ちゅう）の主な成分はどれか。
1. 銅とすず
2. 銅と亜鉛
3. 銅とニッケル
4. 鉄とクロム

**正解：2**
解説：青銅は銅＋すず、ステンレスは鉄＋クロム（＋ニッケル）。

### 問23
温度一定のもとで、圧力0.2MPa（絶対圧）・体積6Lの気体を、圧力0.6MPa（絶対圧）にしたときの体積はどれか。
1. 1L
2. 2L
3. 3L
4. 18L

**正解：2**
解説：ボイルの法則 P1V1＝P2V2 → 0.2×6＝0.6×V2 → V2＝2L。

### 問24
断面積5cm²のピストンに20Nの力を加えたとき、断面積100cm²のピストンに生じる力はどれか（パスカルの原理）。
1. 1N
2. 100N
3. 400N
4. 2,000N

**正解：3**
解説：20×100/5＝400N。

### 問25
合金の一般的な性質として、誤っているものはどれか。
1. 成分金属より硬くなる
2. 成分金属より融点が高くなる
3. 成分金属より電気伝導率が低くなる
4. 耐食性が向上する場合がある

**正解：2**
解説：合金の融点は成分金属より**低くなる**ことが多い。

### 問26
引張強さ480N/mm²の材料を安全率6で使用するときの許容応力はどれか。
1. 60N/mm²
2. 80N/mm²
3. 120N/mm²
4. 2,880N/mm²

**正解：2**
解説：許容応力＝基準強さ÷安全率＝480÷6＝80N/mm²。

## 第4部 構造・機能及び整備の方法

### 問27
強化液消火器について、誤っているものはどれか。
1. 消火薬剤は炭酸カリウムの濃厚な水溶液である
2. 霧状に放射する場合は電気火災にも適応する
3. 凝固点は−20℃以下である
4. 棒状に放射する場合は油火災にも適応する

**正解：4**
解説：棒状は普通火災のみ。霧状で普通・油・電気火災に適応。

### 問28
化学泡消火器について、正しいものはどれか。
1. 外筒に硫酸アルミニウム、内筒に炭酸水素ナトリウムを入れる
2. 外筒に炭酸水素ナトリウム、内筒に硫酸アルミニウムを入れる
3. 指示圧力計が取り付けられている
4. 電気火災に適応する

**正解：2**
解説：外筒A剤＝炭酸水素ナトリウム（アルカリ性）、内筒B剤＝硫酸アルミニウム（酸性）。指示圧力計はない。電気火災には不適。

### 問29
ABC粉末消火器の消火薬剤の主成分と着色の組合せとして正しいものはどれか。
1. 炭酸水素ナトリウム － 白色
2. りん酸アンモニウム － 淡紅色
3. 炭酸水素カリウム － 淡紅色
4. りん酸アンモニウム － 紫色

**正解：2**

### 問30
蓄圧式消火器の指示圧力計の緑色範囲として一般的なものはどれか。
1. 0.07〜0.098MPa
2. 0.5〜0.7MPa
3. 0.7〜0.98MPa
4. 1.0〜1.5MPa

**正解：3**

### 問31
指示圧力計のない蓄圧式消火器はどれか。
1. 強化液消火器
2. 機械泡消火器
3. 二酸化炭素消火器
4. 蓄圧式粉末消火器

**正解：3**
解説：CO2消火器とハロン1301消火器には指示圧力計がない（質量で確認）。

### 問32
加圧式粉末消火器の部品で、サイホン管の先端に取り付けられ、粉末がサイホン管に入り込むのを防ぐものはどれか。
1. 逆流防止装置
2. 粉上り防止用封板
3. 安全栓
4. ノズル栓

**正解：2**
解説：逆流防止装置はガス導入管の先端に付き、粉末のガス導入管への逆流を防ぐ。

### 問33
消火器の内部及び機能の点検の時期として、誤っているものはどれか。
1. 化学泡消火器は設置後1年を経過したもの
2. 加圧式粉末消火器は製造年から3年を経過したもの
3. 蓄圧式消火器は製造年から3年を経過したもの
4. 二酸化炭素消火器は内部及び機能の点検の対象外

**正解：3**
解説：蓄圧式は製造年から**5年**。

### 問34
蓄圧式粉末消火器を分解するときの手順として、最初に行うべきものはどれか。
1. キャップスパナでキャップを外す
2. 総質量を測定し、指示圧力計の指度を確認する
3. 消火薬剤をポリ袋に移す
4. バルブ部分を抜き取る

**正解：2**
解説：総質量測定・指度確認 → 排圧 → 指針0確認 → キャップを外す → バルブを抜く → 薬剤を移す の順。

### 問35
粉末消火器の本体容器内の清掃方法として、適切なものはどれか。
1. 水で洗い、自然乾燥させる
2. 中性洗剤で洗う
3. 窒素ガスや除湿した圧縮空気で吹き払う
4. ブラシに油を付けてこする

**正解：3**

### 問36
消火器の耐圧性能の点検（水圧試験）を行う時期として正しいものはどれか。
1. 製造年から5年を経過したもの
2. 製造年から8年を経過したもの
3. 製造年から10年を経過したもの
4. 製造年から15年を経過したもの

**正解：3**
解説：製造年から10年経過（または著しい腐食）。以後3年ごと。

### 問37
化学泡消火器の充てん方法として、誤っているものはどれか。
1. 外筒の消火薬剤は、水に少しずつ入れてかき混ぜながら溶かす

## 第5部 規格

### 問38
大型消火器の消火剤の量として、誤っているものはどれか。
1. 強化液消火器 60L以上
2. 機械泡消火器 20L以上
3. 粉末消火器 20kg以上
4. 二酸化炭素消火器 30kg以上

**正解：4**
解説：CO2は**50kg以上**。ハロゲン化物が30kg以上。

### 問39
消火器の動作数について、正しいものはどれか（安全栓を外す動作等を除く）。
1. 手さげ式の化学泡消火器は1動作
2. 据置式の消火器は2動作以内
3. 背負式の消火器は3動作以内
4. 車載式の消火器は4動作以内

**正解：2**
解説：手さげ式1動作（化学泡を除く）、化学泡・据置式・背負式2動作以内、車載式3動作以内。

### 問40
消火器の使用温度範囲について、正しいものはどれか。
1. 化学泡消火器は0℃以上40℃以下

3. 化学泡以外は5℃以上40℃以下
4. 化学泡以外は−10℃以上40℃以下

**正解：2**

### 問41
消火器の安全栓について、誤っているものはどれか。
1. 内径2cm以上のリング部を有する
2. リング部は赤色仕上げとする
3. 上方向に引き抜くよう装着されている
4. 1動作で容易に引き抜くことができる

### 問42
消火器のろ過網について、正しいものはどれか。
1. 目の最大径はノズルの最小径の2分の1以下
2. 目の最大径はノズルの最小径の4分の3以下
3. 目の部分の合計面積はノズル開口部の最小断面積の10倍以上
4. 蓄圧式粉末消火器に設けなければならない

**正解：2**
解説：目の最大径3/4以下、合計面積30倍以上。設置対象は手動ポンプ式水消火器・酸アルカリ・化学泡。

### 問43
消火器の放射性能について、正しいものはどれか。
1. 放射時間は20℃で5秒以上
2. 放射時間は20℃で10秒以上
3. 化学泡消火器は充てん消火剤の90%以上を放射
4. 粉末消火器は充てん消火剤の85%以上を放射

**正解：2**
解説：放射量は90%以上（化学泡は85%以上）。

### 問44
手さげ式とすることができる消火器の質量（保持装置等を除く）の上限はどれか。
1. 20kg以下
2. 28kg以下
3. 35kg以下
4. 40kg以下

**正解：2**
解説：28kg以下は手さげ・据置・背負、28kg超35kg以下は据置・車載・背負、35kg超は車載のみ。

### 問45

### 問46

### 問48
使用済み表示装置を設けなくてもよい消火器はどれか。
1. 手さげ式の加圧式粉末消火器（開閉バルブ付き）
